# YouTube Website Clone

A modern **YouTube website clone** built to recreate the core experience of YouTube, including video browsing, search, categories, navigation, and responsive layouts.

## 🚀 Features

* 🏠 Home page with recommended videos
* 🔍 Search functionality
* 📺 Video player page
* 📂 Category and topic browsing
* 👍 Like, dislike, share, and save actions
* 💬 Comments section
* 👤 Channel pages
* 📱 Responsive design for mobile, tablet, and desktop
* 🌙 Dark/light theme support
* 📌 Sidebar navigation
* 🎬 Video thumbnails and metadata

## 🛠️ Tech Stack

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/youtube-clone.git
cd youtube-clone
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The website will then be available through the local development URL shown in your terminal.

## 🎯 Project Goal

The goal of this project is to practice modern web development by recreating the user interface and core interactions of a video-sharing platform.
